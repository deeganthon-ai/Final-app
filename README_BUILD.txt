HomeFit Pro - PPL Premium Build

What this zip includes:
- Expo React Native Android project for Samsung S23 Ultra
- Push / Pull / Legs only training structure
- No separate Arms & Shoulders or Chest & Back workout categories
- Smart PPL workout generator
- Exercise database with dumbbell, barbell, tricep bar, bodyweight, bench and York Multi Gym exercises
- Exercise search, filters, swaps and custom exercise creation
- Editable sets, reps, weights and rest times
- Rest timer
- Workout history, volume tracking and PR detection
- Progressive overload suggestions using previous PRs
- Recovery/readiness score: sleep, energy, soreness and stress
- Weekly coaching messages and plateau/deload style guidance
- Expanded goal options: fat loss, recomp, build muscle, strength, lean bulk, maintenance, aggressive cut, endurance, athletic performance and custom
- Nutrition tracker with calories, protein, carbs and fat
- Open Food Facts barcode lookup
- Camera barcode scanner via expo-camera
- Manual barcode entry
- Local UK supermarket-style food templates for common Morrisons/Sainsbury's style foods
- Custom foods, saved meals, recent/favourite foods and portion adjustment
- Water tracker
- Weight and waist tracking with auto calorie adjustment from weigh-ins
- Backup/export and restore text
- Reset app option
- Dark premium card-based UI with bottom navigation
- GitHub Actions workflow for EAS Android preview build
- No Health Connect dependency

Build steps:
1. Upload/unzip this project into your GitHub repository.
2. In GitHub, add EXPO_TOKEN as a repository secret.
3. Go to Actions and run the EAS Android Preview workflow.
4. Download the APK/AAB artifact from Expo when build completes.

Local checks:
npm install
npm run prebuild-check
npx expo-doctor
